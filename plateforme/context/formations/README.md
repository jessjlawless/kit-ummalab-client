# Mes formations — notes complètes

Une fiche par formation, livre ou coaching (ex. `vente-closing.md`), écrite depuis l'onglet **Chat** du dashboard
(« ajoute à mes connaissances ce que j'ai appris en formation : … ») ou à la main.

- Ces fiches ne sont **pas** injectées telles quelles dans les prompts (trop longues).
- L'essentiel actionnable, condensé avec sa source, va dans `context/05_formations.md`, lui injecté dans toutes les générations.
- On ne note que ce que tu as réellement appris : rien d'inventé.
